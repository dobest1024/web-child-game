# 魔方小课堂（6–10 岁魔方教程小游戏 · H5 原型）

## 运行
ES Module 需要通过本地服务器打开（不能直接双击 index.html）：

```bash
python3 -m http.server 8766
# 浏览器打开 http://localhost:8766
```
手机/平板在同一 Wi-Fi 下访问 `http://<电脑IP>:8766` 即可试玩。three.js 已放在 `vendor/`，不依赖外网 CDN。

## 课程规划
- 🌱 入门 · 层先法（11 关，已全部完成）
  1. 认识魔方一家：点选中心块/角块/棱块
  2. 转动小能手：R L U F B、整体转动 y，魔法咒语 R U R' U' ×6 复原
  3. 种一朵小白花：3 道小题，学会「腾空位」
  4. 白色大十字：对颜色 + 转两下
  5. 白色第一层：白角回家，咒语 R U R' U'
  6. 中间第二层：倒立的 T，往右放 / 往左放
  7. 黄色十字：F R U R' U' F'（点 → 小拐角 → 横线 → 十字）
  8. 黄色顶面：小鱼咒语 R U R' U R U2 R'
  9. 顶层角块归位：车灯放后面，R' F R' B2 R F' R' B2 R2
  10. 顶层棱块归位：拼好的面放后面，R U' R U R U R U' R' U' R2
  11. 完整还原挑战：随机打乱，自动识别当前在第几步，全程可提示
- 🚀 进阶 · 四步 CFOP（8 关，完成入门第 11 关后解锁）
  1. 直接做十字：不种小白花，白棱直接送到底部
  2. F2L 配对入槽：6 个小公式 R U R' / R U' R' / R U2 R'、F' U F / F' U' F / F' U2 F
  3. F2L 四个槽：卡在别的槽里就用 R U R' 请出来
  4. OLL 顶面（上）：黄十字 + 小鱼 / 反小鱼 / 大H / 派
  5. OLL 顶面（下）：车头灯 / T字 / 领结（含小写 r：右边两层一起转）
  6. PLL 角块：相邻换角（A）/ 对角换角（Y）
  7. PLL 棱块：换棱 A / 换棱 B / 对面换棱（H）/ 邻边换棱（Z）
  8. CFOP 完整挑战：自动识别当前在 6 步中的哪一步
- 🏆 高手 · 完整 CFOP（78 个公式，待做）
- 其他魔方：二阶 / 金字塔 / 斜转（待做）

## 代码结构
| 文件 | 作用 |
| --- | --- |
| `js/cube.js` | 魔方逻辑模型（含整体转动 y）、各层完成度判定，纯 JS 可测试 |
| `js/stages.js` | 层先法 8 个阶段 + CFOP 6 个阶段：公式、咒语按钮、按当前状态计算提示、随机出题 |
| `js/view.js` | three.js 3D 渲染：拖动视角、点选、转层动画、高亮 |
| `js/levels.js` | 课程与关卡数据（步骤式脚本，加新关卡主要改这里） |
| `js/main.js` | 页面切换、步骤引擎、星级与本地存档 |
| `js/audio.js` | 合成音效 + 中文语音朗读 |

关卡步骤类型：`say` 说话、`show` 展示/演示、`find` 点选小块、`teach` 学一个转动、`spell` 魔法咒语、`goal` 自由解题（带提示/撤销/重来）。

提示是根据「魔方现在的样子」实时计算的，孩子不按标准路线走也能拿到正确的下一步；算出的路线会被记住，避免来回反复。

## 测试

```bash
node tests/cube.test.mjs
node tests/stages.test.mjs          # 每个阶段随机出题、跟着提示走到完成；N=200 可加大题量
```
