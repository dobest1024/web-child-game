# 魔方小岛

给 6–10 岁孩子的魔方复原闯关游戏。原生 JavaScript + Vite + cubing.js，没有后台、账号或额外数据采集。

## 运行

```sh
npm install
npm run dev -- --port 5188
```

打开 http://localhost:5188 。生产构建 `npm run build`，部署目录为 `dist/`。

## 功能

- 三阶层先法 7 关、二阶 4 关、金字塔 4 关、CFOP 分步教学 24 关。
- 可旋转观察的真实 3D 模型，顺逆时针操作、撤回、重置、自动演示、逐步提示。
- 魔方小学堂：24 个知识小游戏，覆盖整块认识、动作读法、层先法路线、情况识别、找错复盘、直观 F2L；19 个 3D 动作示范、6 张真实局面识别图。
- 连续复原：三阶 16 个检查点、二阶 6 个、金字塔 6 个；从网站内随机打乱开始，保持同一颗魔方逐步复原，可手动转动、撤回、重新规划和保存后继续。
- 原探险地图仍是预设局面的专项练习。网站不支持实体魔方拍照识别或录入外部配色。
- 自由练习支持打乱和真实状态判定；提示按历史逆序回退，不声称是最短解法。
- 23 张入门公式卡，搜索与筛选。未收录完整 57 OLL / 21 PLL。
- 本地 IndexTTS 2.5 生成的中文女声，原39关、CFOP分步讲解、小学堂知识题与答题反馈、连续路线各阶段讲解、公式解释、动作提示与鼓励语，共 287 条。支持慢速和静音；切换 / 关闭时停止旧音频。
- 每关首次完成 3 星，徽章、浏览器本地进度保存，手机和平板布局。

## 新内容怎么学

1. 进入“魔方小学堂”，先做基础认知和动作读法。选错会给具体原因，可以重试；答对获得知识印章。
2. 选择三阶、二阶或金字塔完整路线，可选 5 / 15 / 25 步打乱。金字塔另随机调整尖角。
3. 每小关先看目标块和讲解，再点“跟着转这一步”或“演示这一组”；也可以展开手动操作。
4. 目标由真实魔方状态检查。下一小关继续使用当前魔方，不更换局面；转了不同路线可以重新规划。
5. 关闭练习自动保存，回到小学堂点“接着上次的魔方”。知识印章与旧关卡星星分别记录。

路线求解器只读取当前局面，不倒放打乱历史。三阶逐棱十字、逐角第一层、逐棱第二层、两步顶面翻色和换位；完整路线使用普通六面转动。二阶先四个底角，再翻顶面和换顶角；金字塔先对尖角、轴角，再底面棱及最后三棱。阶段中途可能暂时扰动已完成块，在检查点保证累计目标。路线以教学阶段为先，不声称最短解。

计算在 Web Worker 内进行；查表保留约数 MiB。保存数据只含本地打乱与转动历史，不上传儿童信息。

## CFOP 怎么学

- C：3 关，先找白棱、对齐侧色、再送到底层。
- F：4 关，左右成对入槽、请出角块配对、白色朝上时配对。是代表练习，不是全部 41 种 F2L。
- O：10 种两步 OLL 情况，黄十字 3 种 + 黄角 7 种。
- P：6 种两步 PLL 情况，角块 T / Y + 棱块 Ua / Ub / H / Z；最后另练顶层对齐。

每关都有“先观察 → 跟着转 → 检查”：真实初始状态生成的顶视识别图、拿法、动作分组及目的、每步中文方向、实时白十字 / 四对角棱 / 黄面 / 六面状态检查。自动演示会等待当前动作与动作组语音结束；可暂停、撤回、重播，不重复奖励星星。手机跟练时模型保持可见。

教学内容在 `src/cfop.js`，状态与识别图数据在 `src/cfop-state.js`，教学视图在 `src/teaching.js`。旧版 CFOP 四关成绩按练习 ID 迁移。

## 本地重新生成语音

使用 BaoCut 自带 audiocpp_cli、用户已安装的 IndexTTS 2.5 Q8 模型和 zh-female 参考音色；不上传文本到外部 TTS。

```sh
node scripts/voice-manifest.mjs
python3 scripts/generate-voice.py
```

`voice-manifest.mjs` 会同步生成 `src/voice-manifest.json`；改教学文本后重新运行以上命令即可。现有内容按文本哈希缓存。音色署名见 `public/audio/CREDITS.txt`。模型不随网站分发。
