# 汉字积木

部件方块慢慢往下掉，放到"好朋友"旁边（左右结构）或上面（上下结构）就拼成一个字：日月明、木子李、口天吴。
现开放 1—6 年级，每个年级 10 关，共 60 关、147 个汉字，按部件、偏旁和形近字分组练习。
拼出来的字进「汉字图鉴」，点一点能听字音和组词。

| 关 | 名字 | 要拼的字 |
|---|---|---|
| 1 | 日月明（教学关） | 明 林 从 |
| 2 | 小大尖 | 尖 尘 早 男 |
| 3 | 女字旁 | 好 妈 姓 明 |
| 4 | 姓氏歌 | 李 张 吴 古 |
| 5 | 小 Boss：乱字小妖 | 前 4 关的字；拼对 6 个打败它，它会往空列乱丢方块 |
| 6 | 小青蛙 | 清 晴 情 请 |
| 7 | 小公鸡和小鸭子 | 他 地 池 河 哥 |
| 8 | 一个接一个 | 伙 伴 住 秋 |
| 9 | 猜字谜 | 动 加 江 红 字 爸 |
| 10 | 大 Boss：部件大魔王 | 全部 33 个字；拼对 8 个打败它 |

一年级保留原有字表；二至六年级为核心识字拓展。部件拆分参考 cjkvi-ids，具体来源见 `js/chars.js`。

- 代码：纯 HTML + Canvas + 原生 JS，无构建步骤。加载顺序 `chars → audio-list → board → save → audio → game → main`
- 规则：棋盘规则（怎么算拼对、方块出在哪一列）是 `js/board.js` 里的纯函数；字表和关卡在 `js/chars.js`；引擎 `js/game.js`
- 落下的方块只和"本列最上面一块"（上下拼）或"相邻列最上面一块"（左右拼）拼；放在另一半旁边但位置不对会弹回去并提示结构，同一题弹回两次后第三次就先放下
- 连输会变简单（最多帮 3 次）：开局方块少、落得慢、5 秒没放就亮出答案列、快满时小扫帚帮忙
- 存档键 `hanzi-blocks-save-v1`，改结构时同时改 `defaultSave()` 和 `fillSave()`
- 操作：点一列，方块就移过去落下；键盘 ← → 移动、↓ / 空格 / 回车放下、R 再听一遍、Esc 暂停
- 读音：`audio/zi-*.mp3`（字音）、`audio/ci-*.mp3`（组词）是 audio-cmn 的真人录音（CC BY-SA，见 `audio/CREDITS.txt` 和 `audio/manifest.json`），用 `npm run audio` 重新下载；音效用 WebAudio 现场合成

## 运行和测试

```sh
python3 -m http.server 8813   # 在本目录，打开 http://127.0.0.1:8813
npm test                      # 字表、录音完整性、棋盘规则、存档清洗，以及十关的自动拼字模拟和横竖屏布局
```

浏览器自测：在控制台加载 `tests/bot.js` 后运行 `runLevel(关号, 放错比例, 反应秒数, 'near' 或 'stack')`，结果在 `window.__res`。
