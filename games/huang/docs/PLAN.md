# 王冠峡谷

## 目标与范围
参考 https://github.com/amiaoapp/inkwave 的实际技术栈，制作皇室战争式的在线网页游戏。使用原创程序化美术，不使用原作客户端或资源。用户已确认先交付完整可运行的本地/局域网版本，无需本次公网发布。

## 技术选择
- Three.js 0.186.1、原生 JavaScript ES Modules、HTML/CSS，无前端框架。
- 程序化竞技场、角色、动画、音效；无需外部 CDN 或素材服务。
- Node.js + WebSocket 提供一条命令启动的本地服务。
- Cloudflare Worker + 每房间一个 Durable Object，复用同一套战斗和房间逻辑。
- 与 inkwave 的客户端转发模式不同，本游戏服务端权威模拟，客户端只提交出牌指令。

## 必须交付
1. 双路、河流与桥梁、双方各三塔，自动寻敌、行军、攻击与塔摧毁。
2. 八张可轮换卡牌、四张手牌、圣水、兵种差异、范围法术、己方落兵区域校验。
3. 3 分钟比赛、末分钟双倍圣水、加时、胜负结算、再来一局。
4. AI 练习、创建/加入房间、房间码与分享链接、双方准备、同步对战。
5. 掉线重连与超时判负、非法指令和资源校验、房间清理。
6. 桌面与手机操作、键盘选卡、音效开关、使用说明。
7. 游戏规则单测、真实双 WebSocket 集成测试、浏览器视觉与交互验收。
8. README、本地运行、局域网访问、Cloudflare 配置与构建产物。

## 验收边界
本地运行与局域网监听可验证；无第二台物理设备时不声称完成真机验收。Cloudflare 配置必须通过构建/打包检查，未发布时明确标注。
