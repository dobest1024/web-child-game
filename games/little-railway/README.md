# 小小铁路工程师

面向 6–12 岁的单人铁路规划小游戏。原生 HTML、CSS、JavaScript 和原创 SVG 插画，无外部图片、字体或音频请求。

## 玩法

- 春日森林、糖果海湾、星光雪山，三个主题共 18 关，全部可自由选择。
- 从绿色起点点击或拖动铺轨，接齐动物朋友，再连接红屋顶终点。
- 树木和水面不能通行，木桥可以。路线不可交叉；点击旧轨道可以退回该格。
- 到站得一星，收齐星星纪念章和不超过巧手目标各加一星；超过目标不阻止过关。
- 发车时可切换双倍速度，停止后火车回到起点，保留轨道供修改。
- 自由建造支持树木、河水、桥梁、最多四位乘客和四枚星星，以及三种风景。布置地图后重新铺轨。
- 自由建造点击保存后存入当前浏览器；星星进度自动保存。清除站点数据会清除存档，不跨设备同步。
- 键盘：Tab 进入地图，方向键移动焦点，空格或回车铺轨，Backspace 撤回。
- 支持系统减少动态效果设置。音效在首次点击或键盘操作后启用，页首可静音和调音量，设置保存在当前浏览器。

这是单条路线的规划与建造游戏，当前没有多列车调度或多人联机。

## 运行与验证

从仓库根目录运行 `npm start`，访问 `/little-railway/`，或从大厅的益智解谜分类进入。

```sh
node --test games/little-railway/tests/*.test.mjs
npm run build
npm test
npm run build:static
```

`levels.js` 保存关卡和三星参考路径；`engine.js` 负责铺轨校验、结算、存档校验；`art.js` 绘制角色和场景；`audio.js` 合成铺轨、汽笛、车轮、上车、收集和到站音效；`game.js` 管理交互与火车动画。修改关卡时用参考路径测试确认仍可获得三星。

本轮验证：18 条参考路径全部获得三星；浏览器实际完成第一关和自建桥梁关卡，验证键盘、鼠标拖动、星星存档、地图保存后刷新恢复、大厅搜索分类与 iframe 加载。1280×900 和 390×844 布局已检查；尚未做实体手机和儿童试玩。

浏览器截图保存在本地忽略目录 `artifacts/desktop.png`、`artifacts/mobile.png` 与 `artifacts/snow-workshop.png`，不会进入静态发布包。

音效验证：浏览器实际手势后 AudioContext 为 running，铺轨创建音源；静音后铺轨不创建新音源。七类核心音效经 OfflineAudioContext 渲染为非静音波形且无削波。静音与后台播放限制另有单元测试；未进行实体手机扬声器听测。
