# 小小店长

开一家森林小店：给小动物装货、认钱币、收钱、找零钱、换零钱、看钟表。
现开放 1—6 年级，每个年级 10 关，共 60 关。由认币、找零与购物，逐级拓展到数量关系、时间和单位换算、面积、平均数、小数、折扣、百分数与比。
赚到的金币可以装修小店（遮阳棚、招牌、店长帽子、门口装饰），服务过的小动物和用过的钱币会进图鉴。

| 关 | 名字 | 题型 |
|---|---|---|
| 1 | 开张啦 | 装货（数数 1–5），教学关 |
| 2 | 硬币宝宝 | 认硬币 1角 / 5角 / 1元，装货 |
| 3 | 纸币朋友 | 认纸币 5元 / 10元 / 20元 |
| 4 | 凑一凑 | 收钱（整元），认钱币 |
| 5 | 小 Boss：大胃王熊熊 | 装货、收钱；一边做生意一边点掉小蜜蜂 |
| 6 | 几时开门 | 看整点钟表，收钱 |
| 7 | 找零钱 | 找零（5元、10元），收钱 |
| 8 | 角角换换 | 1元换成角，收几元几角 |
| 9 | 半点钟 | 半点钟表、找零、收钱；收银台不显示合计 |
| 10 | 大 Boss：调皮猴王 | 全部题型；点掉飞来的香蕉皮 |

- 代码：纯 HTML + DOM + 原生 JS，无构建步骤。加载顺序 `money → data → tasks → levels → save → audio → art → game → view → main`
- 规则：金额一律用"角"做整数单位；出题和判对错在 `js/tasks.js`（纯函数），引擎 `js/game.js` 不碰 DOM，`js/view.js` 负责画
- 存档键 `little-shop-save-v1`，改结构时同时改 `defaultSave()` 和 `fillSave()`
- 操作：点货架 / 钱币 / 选项；键盘数字键选钱或选项、↑↓ 加减货物、退格拿回、回车提交、空格点掉捣乱的小东西、Esc 暂停
- 钱币和钟表是原创 SVG（印着"玩具钱"，不临摹真钱）；小动物和货物用系统表情符号；音效用 WebAudio 现场合成

## 运行和测试

```sh
python3 -m http.server 8812   # 在本目录，打开 http://127.0.0.1:8812（自测可加 ?speed=4 让时间走快）
npm test                      # 钱的计算、每种题的标准答案和范围、存档清洗，以及十关的自动营业模拟
```

浏览器自测：在控制台加载 `tests/bot.js` 后运行 `runLevel(关号, 做错比例, 反应秒数)`，结果在 `window.__res`。


内容按年级核心知识组织，供游戏化学习与复习；不宣称逐课覆盖某一版教材。原一年级关卡编号和存档键保持兼容。
