# 口算大作战

捣蛋怪举着算式走向糖果城堡，点写着答案的炮台（或键盘直接打数字）把它打跑。
现开放 1—6 年级，每个年级 10 关，共 60 关。逐级练习整数四则运算、运算律、平均数、小数、分数、百分数、比、方程及常见几何量。

- 设计：`docs/01-设计理念.md`、`docs/02-关卡设计.md`
- 代码：纯 HTML + Canvas + 原生 JS，按 `questions → levels → save → audio → game → main` 顺序加载，无构建步骤、无第三方素材
- 题目生成：`js/questions.js`（纯函数）；关卡和怪物：`js/levels.js`
- 存档键 `math-defense-save-v1`，改结构时同时改 `defaultSave()` 和 `fillSave()`
- 操作：点炮台 / 打数字（比大小用 `<` `=` `>`，也可以用 `,` `.`）；空格放彩虹大招；Esc 或 P 暂停

## 运行和测试

```sh
python3 -m http.server 8803   # 在本目录，打开 http://127.0.0.1:8803
npm test                      # 题目答案与范围、干扰项、存档清洗、引擎模拟（会答错 / 漏题 / 发呆的小玩家）
```

浏览器自测：在控制台加载 `tests/bot.js` 后运行 `runLevel(关号, 答错比例, 反应秒数)`，结果在 `window.__res`。


内容按年级核心知识组织，供游戏化学习与复习；不宣称逐课覆盖某一版教材。原一年级关卡编号和存档键保持兼容。
