# ⚫⚪ 围棋小课堂 — 给小朋友的围棋进阶网站

一个**纯静态、可离线、无广告、图文并茂**的围棋教学网站，面向 6 岁起步的小朋友，
从完全不会一直教到会下、会算、会想、输得起。

## 怎么打开

直接用浏览器打开 `index.html` 即可。**绝大部分功能（所有课程、棋盘图、小测验）双击即用，无需联网或服务器。**

> 仅「练习场」的互动棋盘用到 JavaScript；个别浏览器对本地文件的脚本有限制时，
> 可在本目录下启动一个简易服务器再访问：
> ```bash
> python3 -m http.server 8000   # 然后打开 http://localhost:8000
> ```

## 技术说明（给家长/开发者）

- 无任何第三方依赖、无构建步骤，HTML + CSS + 原生 JS。
- `js/goban.js`：用简单坐标记号把棋谱渲染成 SVG 棋盘（课程里所有棋形图）。
- `js/play.js`：互动棋盘，**真实实现了气、提子、禁着点（自杀）、打劫**规则。
- `js/quiz.js`：每课末尾的小测验。
- 课程中的**征子、枷、倒扑、接不归、死活**等战术图，均已用同一套围棋规则引擎
  逐手验证为合法、正确的棋形，而非示意摆放。

每一关都配有彩色棋盘图、生活化小故事、重点提示框和一道互动小测验，适合家长陪读、每天一关。
