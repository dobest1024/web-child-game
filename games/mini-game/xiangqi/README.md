# ♟️ 象棋小棋手 · 中国象棋启蒙教学网站

为 6 岁左右的小朋友打造的中国象棋入门乐园。纯静态网站（HTML/CSS/JS），无需安装任何东西，双击即可使用。

## 如何打开
直接用浏览器打开 `index.html` 即可。
或在本目录启动一个本地服务器（推荐，避免某些浏览器的本地文件限制）：

```bash
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 包含的内容（8 个板块）
1. **🏠 首页** —— 欢迎与学习路线
2. **🧩 认识棋子** —— 点棋子卡片，棋盘实时演示每种棋子怎么走（绿点=可走，红圈=可吃）
3. **🎮 自由练习** —— 一副完整的棋，孩子可点子走棋、和家长对弈，可一键重摆
4. **🪜 进阶之路** —— 6 个由浅入深的台阶，每级有目标和小任务
5. **⚔️ 战法** —— 马后炮、双车错、对面笑等经典杀法的童趣讲解
6. **💗 下棋心理** —— 沉住气、输了不哭、懂礼貌等好心态
7. **🧠 学会思考** —— 走棋前问自己的 4 个问题
8. **🎲 趣味问答** —— 5 道小测验，巩固所学

## 走法规则的准确性
棋子走法（含蹩马腿、塞象眼、炮架吃子、兵过河、九宫格、楚河汉界）均按标准中国象棋规则实现，
核心逻辑在 `js/board.js` 的 `legalMoves()` 中，已通过单元测试验证。

## 文件结构
```
index.html      页面结构与 8 个板块
css/style.css   童趣界面 + 棋盘渲染
js/data.js      棋子定义、课程/战法/心理/思考/问答内容
js/board.js     棋盘引擎：渲染 + 走法计算
js/main.js      导航与各板块交互
```
