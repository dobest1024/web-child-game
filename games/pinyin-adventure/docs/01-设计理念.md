# 拼音大冒险 · 设计理念

> 面向：6–12 岁（1–6 年级可选）
> 平台：网页（平板触屏 + 电脑键盘），不需要安装
> 参考：坦克大冒险 `games/tanke/docs/01-设计理念.md`，原则一致，这里只写不同的地方

## 1. 一句话

**小兔跳跳一路向前跑，听到声音，跳起来顶对拼音砖，攒满拼音星就过关。**

## 2. 核心玩法：知识就是操作

小兔**自动向右跑**，孩子只需要一个动作：**点屏幕 / 按空格 = 跳**（长按跳得更高）。
一个手指就能玩，6 岁孩子不会被操作卡住。

每隔一段路出现一道"题"：

1. 小兔头上冒出 🔊，播放读音（比如 `mǎ`）。屏幕右上角永远有 🔊 按钮可以再听一遍。
2. 前方出现 2–4 个写着拼音的砖块（`mā` `má` `mǎ` `mà`）。
3. 跳起来**顶对的砖**：砖块弹出拼音星 ⭐ + 金币，读音再播一遍，连击 +1。
4. 顶错的砖：砖块"咚"一下变灰，**不扣血**，只断连击；对的砖开始发光提示。
5. 全都错过（跑过去了）：这题记进"回炉"，稍后再出。

每关攒满 8 颗拼音星就到终点旗。

### 2.1 不同关用不同"地形"出题（一次只学一样新东西）

| 地形 | 怎么玩 | 练什么 |
|---|---|---|
| 问号砖 | 跳起来顶对的砖 | 听音认拼音（默认玩法） |
| **声调路** | 砖块上除了拼音，还画着声调的样子：平 ˉ、上坡 ˊ、拐弯 ˇ、下坡 ˋ（第一版先做成砖块，分岔路以后再做） | 四声，把"声调的样子"看在眼里 |
| 车厢合体 | 先顶声母砖，再顶韵母砖，两节车厢"咔嚓"合体并读出音节 | 两拼、三拼 |
| 过河 | 河上有两座桥：高处云朵桥、低处木头桥，各写一个拼音。听音后跳上云朵桥或留在木头桥；选错的桥先晃 0.8 秒再消失，掉水后回岸边重来，不扣心 | 易混拼音（b/d、p/q、in/ing） |
| 泡泡收集 | 一串泡泡飘过，只撞写着"整体认读音节"的泡泡 | 分类辨别 |

### 2.2 Boss（每 5 关小 Boss，每 10 关大 Boss）

Boss 好笑不吓人，打法也是答题：

- **声调怪**：砖上画着声调的样子（平、上坡、拐弯、下坡），听音顶对，声调就飞过去砸它一下。
- **字母大盗**：偷走了声母。听音顶对的声母砸它。
- 两个 Boss 隔几秒扔一块滚石，扔之前头上冒红色感叹号，跳过去就行。
- 更多 Boss 见 `02-关卡设计.md`。

Boss 放招前一定先闪光、冒感叹号（≥0.6 秒），被打中只掉 1 颗心，3 颗心。

## 3. 防挫败（照搬坦克的做法）

- **答错不扣血**，只有撞到障碍（小刺猬、水坑）才掉心。知识题永远不会让孩子"死"。
- 同一关失败一次，障碍少一些、跑得慢一些、选项从 4 个减到 3 个，最多帮 3 次。
- 连续失败 5 次出现"先跳过"，跳过的关显示空星，随时回来补。
- 只要过关至少 1 颗星。星星：3 星起步，掉过心 −1，答错超过 2 次 −1。
- 失败页说鼓励的话，并把这关最容易错的那个拼音再读一遍。

## 4. 每一下都有反馈

- 顶对：砖块弹起 + 星星飞向计数器 + "叮" + 读音再播一遍。
- 连击 3 / 5 / 8：飘出"好耳朵！""拼音小达人！"大字。
- 错：轻轻"咚"，不刺耳，不出现 ✗ 大红叉。

## 5. 奖励与收集

- **金币**：商店换小兔的帽子、衣服、跑鞋拖尾特效。
- **拼音图鉴**：每学会一个声母 / 韵母 / 音节，点亮一张卡；卡上能点开听读音，配一个例字和小图。
- **成就**：如"四声小耳朵"（声调路全对一关）、"不怕 b 和 d"。

## 6. 年级选择

开始时选 1–6 年级（之后在地图上随时切换），存档记住上次选择。
**拼音在一年级上册就全部学完**，所以：

- 一年级：两个世界，学全部拼音（声母、韵母、声调、整体认读、拼读、标调）。
- 二至六年级：世界变成"读准字音"——看字选拼音、一/不变调、轻声、多音字、易读错字。
  这部分题库**必须按教材和可靠字表整理**，不凭记忆出题。

## 7. 语音

- 拼音读音用**真人录音**：开放数据项目 audio-cmn（录音 Chen Wang，CC BY-SA），1707 个带声调音节，含声母呼读音。跟游戏一起发布，运行时不调用任何 TTS 服务；署名见 `audio/CREDITS.txt` 和游戏里的「关于」。
- 试过本机 Qwen3-TTS 合成单音节：声调不稳、三四成会多念内容，不用于拼音。英语、古诗的长句以后再评估 TTS。
- audio-cmn 没有轻声音节，二年级「轻声」内容需要另找来源。
- 第一次发声放在"开始"按钮的点击里（iOS / 微信要求）；游戏流程**不等**音频播放结束事件。

## 8. 技术约定

- 纯 HTML + Canvas + 原生 JS，普通 `<script>` 按顺序加载，无构建步骤（与坦克一致）。
- 关卡和题库是数据（`js/levels.js`、`data/*.json`），引擎不写死内容。
- 存档键 `pinyin-adventure-save-v1`，用 `defaultSave()` / `fillSave()` 兼容旧存档。
- 拼音规则（标调位置、ü 去点、整体认读判定）写成纯函数并有 Node 测试。
