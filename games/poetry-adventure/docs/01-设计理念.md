# 古诗大作战 · 设计理念

> 面向：6–12 岁（1–6 年级可选，目前开放一年级）
> 平台：网页（平板触屏 + 电脑键盘），不需要安装
> 参考：坦克大冒险 `games/tanke/docs/01-设计理念.md`、拼音大冒险 `games/pinyin-adventure/docs/01-设计理念.md`

## 1. 一句话

**小鸡提着篮子接住天上掉下的字，帮小鸭子用诗句铺桥过河，再和 Boss 对诗！**

## 2. 三种玩法：知识就是操作

| 玩法 | 怎么玩 | 练什么 |
|---|---|---|
| **接字雨** | 顶上显示这一句的格子，诗句先读一遍；字从天上落下（1 个对的 + 1–2 个干扰字），拖动小鸡或按 ← → 移动篮子，按顺序接住 | 一个字一个字记住诗句和顺序 |
| **诗句拼桥** | 河上缺木板，下面是打乱的诗句木板，按顺序点（或按数字键），小鸭子一步步走过去 | 句子的顺序 |
| **飞花令 Boss** | Boss 说上句，从 3 个下句里选对的"出招"打它；Boss 的蓄力条满了会出招打你 | 上句接下句 |

- 干扰字先从同一首诗里挑（考顺序），再从别的诗里挑；飞花令的错误选项是别的诗里字数一样的句子。
- 一年级的孩子很多字还不认识，所以每句诗**先读一遍**，格子里会显示几秒"影子字"；接错或没接住，下一个字会发光提示。

## 3. 防挫败（和拼音大冒险一致）

- **接错字扣一颗心**（教学关不扣），**每接完一句回一颗心**（最多 3 颗）：乱接会输，偶尔失手扛得住。没接住只是"再来一波"，不扣心。
- 拼桥不扣心：点错木板会晃一下，并把该接的那句读出来，对的木板发光。
- Boss 关答错不扣心，只是这题记下稍后再出；只有蓄力条满了（先变红、冒感叹号、响提示音）才被打中。
- 接错或没接住最多的两句，这首诗最后会**再接一次**（只复习一轮，不会没完没了）。
- 同一关失败一次：字落得更慢、干扰字少一个、影子字一直显示、Boss 蓄力时间多 4 秒；最多帮 3 次。
- 连续失败 5 次出现"先跳过"。只要过关至少 1 颗星：3 星起步，掉过心 −1，错超过 2 次 −1。

## 4. 奖励与收集

- **金币**：接对字、铺好木板、答对下句都有，过关按星星再奖励。（商店还没做）
- **诗卡图鉴**：在接字雨或拼桥里完整学会一首诗，得到这首诗的诗卡；点开看全诗，可以"读一读"（逐句高亮朗读）。

## 5. 年级

开始时选 1–6 年级。一年级「诗词花园」是统编版一年级上、下册的 13 首古诗；二至六年级先上锁占位，题库要按教材篇目整理、核对后再开放。

## 6. 语音

- 每句诗和诗名的朗读是**预先生成的 mp3**（本机 BaoCut 的 Qwen3-TTS，`tools/gen_audio.py`，每句多个随机种子挑时长合理的那条），清单在 `audio/manifest.json`。
- 电脑合成语音可能读错多音字，**需要家长抽听**；读错的可以按 id 单独重生成或删掉。
- **没有朗读文件也能完整玩**：诗句文字始终显示，`manifest.json` 读不到就当没有声音。
- 第一次发声放在点击里（iOS / 微信要求），暂停回来、点画面时会再解锁一次；流程从不等待播放结束事件。

## 7. 技术约定

- 纯 HTML + Canvas + 原生 JS，按 `poems → levels → save → audio → game → main` 顺序加载，无构建步骤。
- 诗文在 `js/poems.js`（注释里写了核对来源），关卡在 `js/levels.js`。
- 存档键 `poetry-adventure-save-v1`，`defaultSave()` / `fillSave()` 白名单清洗（只认识真实的诗 id）。
