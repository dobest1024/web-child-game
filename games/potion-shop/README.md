# 魔法药水店

给 5–9 岁孩子的调色益智游戏。孩子是猫婆婆药水店的小学徒，森林里的动物们来买各种颜色的药水：青蛙想变绿躲进草丛，火烈鸟想变回粉红，小熊想要葡萄紫，雪人想要天空蓝……调对颜色，顾客喝下药水就会变身。

## 内容与操作

- 森林早市（两色魔法）、花园午后（比例和浅色）、月光夜市（深色和神秘药水），共 18 关；所有关卡自由选择。
- 点颜料瓶往锅里滴一滴。红、黄、蓝是三原色，第 10 关起出现白色（变浅），第 13 关起出现黑色（变深）。锅里颜色实时变化并有水波动画。
- 每口锅有容量上限（多数 6 滴，第 6 关 8 滴，第 13 关猫头鹰只要 4 滴的小杯）。满了再点会提示，不会加进去。
- 「撤回一滴」拿走最后一滴，「倒掉」清空。「想要」和「锅里」两个圆点并排显示，方便比较。
- 「交给顾客」：比例对就成功。顾客喝下药水后变身（青蛙变绿躲进草丛只露出眼睛，雪人变成天空蓝并飘起雪花，小幽灵从透明变成实心）。
- 交错时顾客会温和地提示，例如“颜色有点偏红哦，再加一点黄试试”；多了配方里没有的颜色、缺了某种颜色、锅里放不下时也有对应提示。交错不扣已得星星。
- 第 16 关「神秘药水」只显示颜色、不告诉名字和配方，要看颜色猜出配方；第 17、18 关有 2–3 位顾客排队，每位要不同的颜色，交对一位再调下一位。
- 星星：调对颜色得 1 星；每位顾客都是第一次就交对，再得 1 星；交出的每瓶药水都用最少滴数（例如橙色 1 红 + 1 黄，而不是 2 红 + 2 黄），再得 1 星。撤回和倒掉不影响星星。
- 星星保存在当前浏览器（`potion-shop:stars:v1`，读取时清洗），只保留每关最好成绩；浏览器禁止存储时照常可玩，结果里会说明无法保存。
- 胜利时先保存星星，再播放装瓶、喝药水、变身动画；动画期间交付、颜料瓶、撤回、倒掉、关卡地图都会禁用。切换标签页只暂停声音，不会打断胜利或跳过结果窗口。
- 音效由 Web Audio 合成，首次点击或按键后才启用，可静音并记住设置（`potion-shop:sound:v1`），页面隐藏时停止并挂起。
- 键盘：Tab 切换按钮，颜料架上用方向键选瓶子，回车 / 空格滴一滴；焦点有明显橙色描边。遵循减少动画设置：关闭 CSS 动画和飞瓶动画，但仍会显示变身后的样子和结果窗口。
- 布局适配桌面 1280×800、手机竖屏 390×844、手机横屏 844×390，以及大厅播放器里横屏手机的实际 iframe 高度 844×328：横屏时顾客、魔法锅、颜料架三栏并排，一屏内无需滚动，无横向滚动。

## 颜色模型

`engine.js` 是纯逻辑，可在 Node 中直接导入。

- 三原色按颜料方式混合：把红黄蓝滴数按最大值缩放到 0–1，作为 RYB 立方体坐标，在 8 个角色（白、红、黄、蓝、橙、紫、绿、棕）之间做三线性插值（Gossett & Chen 方法，角色已调成更适合儿童的鲜艳颜色）。所以红 + 黄是橙色，黄 + 蓝是清楚的绿色，红黄蓝一起是棕色。
- 白色和黑色按各自占全部滴数的比例，把颜色拉向白色或深色。
- 颜色只取决于滴数比例，因此 2 红 + 2 黄与 1 红 + 1 黄颜色完全相同。
- 判定只看滴数比例：化简后的滴数比与配方相同就算对，不比较 RGB 距离。

## 可分辨性（ΔE 阈值）

为了避免“看起来一模一样却被判错”，测试对每一关、每位顾客枚举该关可用颜料在容量内的所有组合：比例与配方不同的组合，与目标颜色的 CIE76 ΔE（Lab）必须 **≥ 10**（`perceptibleDeltaE`）。排队关卡里各位顾客的目标颜色之间也必须 ≥ 10。当前最小值为 10.8（粉红、天空蓝、第 18 关的芒果黄）。

据此做过的取舍：深蓝（蓝 + 黑）在 6 滴锅里最近的错误组合只有 ΔE 8.3，所以第 13 关的锅只有 4 滴；棕色与“橙 + 黑”几乎同色（ΔE 0.8），所以棕色关卡不提供黑色；2 红 + 1 黄、1 红 + 2 蓝这类与邻近比例分不清的颜色没有做成关卡。

## 实现与验证

独立静态项目，无依赖、无外部资源。入口依赖：`index.html`、`style.css`、`game.js`、`levels.js`、`engine.js`、`art.js`、`audio.js`。画面全部为原创内联 SVG，音效全部由 Web Audio 合成。关卡与每位顾客的参考解（最少滴数的滴法）在 `levels.js`，供测试与浏览器自动试玩使用，不在玩家界面显示。

```sh
node --test 'games/potion-shop/tests/*.test.mjs'
```

测试包含：红黄、黄蓝、红蓝、三原色的色相范围，白变浅、黑变深；等价比例判对、不同比例判错、容量上限；18 关参考解都得三星且空锅不算赢；上面的 ΔE 可分辨性穷举；每个错误组合都有提示，提示只提到本关有的颜料、锅满时不建议再加；所有顾客 × 心情 × 变身前后、每关各滴数下的魔法锅、颜料瓶与大厅卡片插图的 SVG 路径有效（`brokenMoves`，并拒绝 NaN / undefined / 科学计数法）；存档清洗与存储抛错不崩溃。

首关手动解法：点一次「红」、一次「黄」，再点「交给顾客」。

尚需实体手机、真实音频输出和儿童试玩验证。
