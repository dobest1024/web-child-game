# 机器人救援队

面向 6–12 岁的单人图形指令游戏。给机器人豆豆编排动作，接上迷路的动物，再返回救援站。原生 HTML、CSS、JavaScript 和原创 SVG，无外部字体、图片或音频依赖。

## 内容

- 18 个任务、三个主题：萌芽森林（顺序与相对转向）、泡泡海岸（重复与开桥）、萤火山谷（障碍判断）。所有关卡自由选择。
- 前进一格、原地左转、原地右转、原地救援；站在黄色开关上执行机关，才能升起桥梁。
- 重复口袋可放 1–12 个普通动作，重复 2–4 次，不支持嵌套。主程序最多 40 项，展开最多 160 步。
- 探路指令：前方有障碍时原地右转，否则前进一格。它不自动寻路或救援。
- 运行、暂停、单步检查、倍速、回起点；当前执行的指令高亮。执行时不能修改程序，回起点后可调整。
- 点指令选中，使用上移/下移或删除；重复口袋中的动作也可单独调整顺序。
- 到站且救齐所有动物得一星；收齐能量星、达到指令张数目标各加一星。重复口袋本身和内部的动作各计一张，不按展开后的执行次数计数。
- 步行、转向、救援、机关、收集、错误、胜利音效，在首次用户操作后启用；可静音，切换到后台自动暂停。
- 关卡星星保存到当前浏览器；同一次打开内切换关卡会保留程序草稿，刷新后程序草稿重置。
- 键盘支持 Tab/回车及 W 前进、A 左转、D 右转、R 救援。地图可用方向键移动焦点，空格或回车查看格子。
- 手机宽度下运行或单步时，滚动到地图，控制栏固定在底部。支持系统减少动态效果设置。

## 文件

`levels.js`：关卡、指令说明及参考解法。
`engine.js`：程序展开、单步规则、碰撞与通关判定。
`game.js`：程序编辑、执行控制与页面交互。
`art.js`：机器人、动物和场景插画。
`audio.js`：原创合成音效。

## 验证

在仓库根目录执行：

```sh
node --test games/robot-rescue/tests/*.test.mjs
npm run build
npm test
npm run build:static
```

18 个参考程序均能三星通关。测试覆盖相对转向、碰撞、救援位置、开桥条件、探路分支、重复执行顺序和上限、失败停止及评分。

浏览器已实测普通关卡与重复、开桥关卡通关，单步观察遇障右转、进度存档、大厅搜索分类和 iframe 加载。390×844 手机尺寸下完成普通关卡；尚未做实体手机或儿童试玩。截图存放在本地忽略目录 `artifacts/`。
