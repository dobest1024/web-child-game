# 坦克大冒险 · 设计理念

> 作者：周逸卿
> 面向：6–9 岁小朋友（也适合和爸爸妈妈、小伙伴一起玩）
> 平台：网页（电脑键盘 + 平板触屏），不需要安装，双击 `index.html` 就能玩

这份文档讲清楚**这个游戏为什么这样做**。以后加任何新东西（新关卡、新敌人、新道具），都先拿这里的原则对一遍。

---

## 1. 一句话

**开着可爱的小坦克，保护宝宝蛋，打败捣蛋机器人和各种好笑的 Boss。**

孩子要能马上读懂：我是谁（小坦克）、我要保护什么（宝宝蛋）、谁是坏蛋（机器人）、我赢了没有（星星、彩带）。

## 2. 七条核心原则

### 2.1 一看就懂，不用读字
- 6 岁的孩子很多字还不认识。所有规则都要能**从画面看出来**：会动的会发光的就是能捡的，有红色感叹号的就是危险的。
- 文字只用来补充，句子要短，最好配一个 emoji 或图标。语音（`say()`）会把关键提示读出来。
- 新东西第一次出现时，用一句话加一个箭头告诉孩子它是什么，**不弹出要点击关掉的说明窗**。

### 2.2 输了也开心（防挫败）
孩子最容易因为"一直过不去"就不玩了。所以：
- **失败不惩罚**：这关捡到的金币照样存好，不扣任何东西。
- **越输越简单**：同一关每失败一次，敌人少 2 个、更慢、开火更少，最多帮 3 次（`fails` / `assist`）。过关后清零。
- **失败页面说鼓励的话**，告诉孩子下次怎么做更好（"保护好宝宝蛋可以拿更多星星哦"）。
- **至少 1 颗星**：只要过关就有星星，不会出现"过了但 0 星"的失落感。
- **三档难度**随时能换：宝宝 / 小勇士 / 大英雄。
- 新增（100 关版）：连续失败 3 次，下一次开局送护盾和小蜜蜂；连续失败 5 次，出现"先跳过"按钮，跳过的关显示空星，随时能回来补。

### 2.3 每一下都有反馈
打中、打爆、捡道具、拿金币，都要有**声音 + 动画 + 数字**：
- 打中：敌人闪白、抖一下、冒星星。
- 打爆：碎块、彩色烟花、金币蹦出来。
- 连杀：飘出"一炮三响！"之类的大字。
- 手感比画面更重要：子弹要快，坦克转弯要利落，撞墙不卡（项目里已经做了 24px 网格自动对齐）。

### 2.4 危险一定先提醒
孩子反应比大人慢，所以**任何伤害都要提前给信号**：
- Boss 放大招前闪光、头上冒感叹号，至少提前 0.6 秒。
- 陨石、喷火口这种从地上或天上来的伤害，先出现阴影或红圈 1 秒以上。
- 不允许"突然出现在身边就打中"的设计。
- 隐身类敌人最多半透明，不能完全看不见。

### 2.5 可爱，不吓人
- Q 版：大眼睛、圆滚滚、粗描边（统一描边色 `#26324A`）、明亮的颜色。
- 敌人是"捣蛋机器人"，被打败是"没电了""冒烟逃跑"，**不出现血、死亡、骷髅、恐怖音效**。
- Boss 要好笑而不是可怕：戴皇冠的机器人、穿裙子的蛋糕女王、会生气鼓起来的河豚。
- 输了是"宝宝蛋被打破啦""坦克都没电啦"，不是"你死了"。

### 2.6 一次只学一样新东西
- 每个世界只带来 **1 种新地形 + 1 种新敌人 + 1 种新道具**（左右）。
- 新东西先在**安全的地方**出现（敌人少的关），等孩子玩明白了，再和旧东西混在一起。
- 越往后，越是把学过的东西**组合**起来出新花样，而不是一直堆新规则。

### 2.7 短小一局，常常有奖励
- 一关 2–4 分钟。孩子的注意力和家长给的玩游戏时间都有限。
- 每关都给点什么：星星、金币，经常还有成就、新帽子。
- 每 3 关一个小 Boss，每 5 关一个大 Boss，节奏是"打几关小兵 → 来个 Boss 爽一下"。

## 3. 游戏结构

```
标题页 ─┬─ 新手教学（6 步：开车、开炮、捡道具、放大招、保护蛋、打 Boss）
        ├─ 1 人玩 / 2 人玩 → 选坦克和难度 → 选关卡 → 开打
        ├─ 商店（帽子 / 涂装 / 贴纸 / 升级）
        ├─ 成就
        ├─ 关卡编辑器（3 个存档位，可以生成分享码）
        └─ 家长设置（存档码、重置）
```

### 3.1 一局的胜负
- **赢**：按这关的玩法完成目标（默认是打败所有敌人；Boss 关是打败 Boss）。
- **输**：宝宝蛋被打破，或者所有玩家都没命了。
- **星星**：3 星起步，丢过命 −1，宝宝蛋被打过 −1，最少 1 星。
- **金币**：打败敌人会掉，过关再奖励"星星 × 5"，Boss 关额外 +10。

### 3.2 宝宝蛋（老家）
- 在地图正下方，被砖墙包着。
- 有血量（宝宝 7 / 小勇士 5 / 大英雄 3），每次被打中后 1.5 秒不会再掉血。
- Boss 关的老家一开始就是铁墙，让孩子专心打 Boss。

### 3.3 玩家坦克
5 种颜色，属性和大招各不相同，**没有"最强"的，只有"适合我的"**：

| 坦克 | 特点 | 血 | 攻 | 防 | 速度 | 大招 |
|---|---|---|---|---|---|---|
| 蓝蓝 | 样样都不错 | 8 | 2 | 1 | 140 | 七彩散弹 |
| 红红 | 攻击最厉害 | 6 | 3 | 0 | 130 | 超级大炮 |
| 绿绿 | 皮最厚 | 10 | 2 | 2 | 112 | 冰冻风暴 |
| 黄黄 | 跑得最快 | 6 | 2 | 0 | 178 | 闪电激光 |
| 紫紫 | 爆炸最厉害 | 7 | 2 | 1 | 135 | 超级炸弹 |

大招靠时间和打敌人充能，充满后按技能键放出。100 关版本再加 2 辆可解锁坦克（见《02-100关设计》第 6 节）。

### 3.4 子弹（武器）
普通弹、大炮弹（伤害 ×2、能打穿两层砖）、散弹（一次 3 发）、穿透弹（穿过敌人）、冰弹（冻住 2.5 秒）、爆炸弹（范围伤害）。武器道具是限时的，到时间就变回普通弹。

### 3.5 道具
从闪光的敌人身上掉出来，每 3 个敌人里有 1 个会闪光。道具图鉴在暂停页可以看。

### 3.6 金宝宝
普通关有 60% 的机会在中途冒出一个金色机器人，它不会开火、只会逃跑，抓住给 15 金币。这是孩子最爱的惊喜时刻，所以**金宝宝逃走也不算失败**。

### 3.7 双人模式
- 同一个键盘：1P 用 WASD + J/K，2P 用方向键 + Enter/右 Shift。
- 两人共用宝宝蛋，各自有命。一个人没命了，另一个人还能继续。
- 双人模式的意义是**一起玩**，所以永远不能有"玩家互相伤害"。

### 3.8 长期目标（为什么还想再玩）
- **收集**：星星、帽子、涂装、贴纸、成就。
- **成长**：用金币升级血量、攻击、速度、充能。升级只是"稍微强一点"，不能强到让关卡失去挑战。
- **创造**：关卡编辑器，做好后把分享码发给朋友。

## 4. 画面与声音

- 画面：Canvas 直接画，不用图片文件。逻辑尺寸 720×588（地图 15×11 格，每格 48px，顶部 60px 状态栏），按屏幕大小缩放。
- 每个世界一套配色（地面、砖、铁、水、草丛、背景渐变），见 `js/data.js` 的 `THEMES`。
- 声音全部用 WebAudio 现场合成，不用音频文件；每个世界一首背景音乐，Boss 战换成更激烈的音乐。
- 语音提示用浏览器自带的中文朗读（`speechSynthesis`）。

## 5. 技术约定（给开发者）

- **纯 HTML + Canvas + 原生 JS**，用普通 `<script>` 标签按顺序加载，不用打包工具、不装依赖。直接用 `file://` 打开必须能玩。
- 加载顺序：`data → meta → audio → draw → game → tutorial → editor → main`。新文件按依赖插进这个顺序。
- 所有关卡用固定种子生成（`mulberry32`），**同一关每次打开都一样**。
- 存档在 `localStorage`（键名 `tanke-save-v2`）。`fillSave()` 负责补字段、兼容老存档、清洗非法值。**任何新存档字段都要在 `defaultSave()` 和 `fillSave()` 里同时处理。**
- 从存档码、分享码读进来的数据一律当作不可信：只接受白名单字符和合理范围内的数字，不能拼进 `innerHTML`。
- 调试：`window.__tk` 暴露内部状态；网址加 `?unlock=1` 可以解锁全部关卡。
- 界面文字全部是简体中文。**标题页和通关页必须显示"作者：周逸卿"。**

## 6. 做与不做

| 做 | 不做 |
|---|---|
| 多给奖励、多夸孩子 | 体力值、每日登录、限时活动 |
| 金币只能靠玩游戏赚 | 任何真实付费、广告、外链 |
| 本地存档 + 存档码 | 账号、联网、收集个人信息 |
| 失败后自动变简单 | 失败扣金币、扣星星 |
| 危险先提醒 | 秒杀、看不见的攻击 |
| 可爱、好笑 | 血腥、恐怖、骷髅 |
| 玩家互相帮忙 | 玩家互相伤害 |
