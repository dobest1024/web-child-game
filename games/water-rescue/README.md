# 水滴救援队

给 6–10 岁孩子的管道连通益智游戏。旋转水管，打开阀门，再让小水滴沿着水路前进，浇开每一朵小花。

## 内容与操作

- 晨露花园、贝壳海湾、月光温室，共 15 关；所有关卡自由选择。
- 点击管道顺时针旋转。直管、弯管、三通、十字管依次出现；水源与花盆不能旋转。
- 第 7 关起加入阀门。点击阀门开关，不改变管口方向。
- 放水以逐层连通方式动画展示，支路同时分流。花朵喝水后盛开；管口没接好则标红；关闭的阀门会截断水路。
- 所有花朵喝到水且所有通水管口不漏水才算通关。未连接水源的备用管不漏水。
- 通关得一星，调整次数不超过关卡目标、两次以内放水成功各加一星。失败不扣已得星星。撤回会恢复上一布局及调整次数。
- 水流可暂停 / 继续，速度可切换；重新开始会恢复本关初始布局与本次计数。
- 星星自动保存到当前浏览器，本关未完成布局刷新后重置。
- 音效在首次用户手势后启用，可静音并记住设置。页面隐藏会暂停水流、停止音效。
- 键盘：Tab 进入地图，方向键移动，回车 / 空格旋转或切换阀门。移动尺寸播放时控制栏固定在底部。遵循减少动画设置。

## 实现与验证

独立静态项目，无依赖安装和外部资源。入口依赖：`index.html`、`style.css`、`game.js`、`levels.js`、`engine.js`、`art.js`、`audio.js`。从项目统一网关访问 `/water-rescue/`。

`engine.js` 使用有限格点的广度优先连通模拟，不模拟真实流体压力、体积或水损耗；分流时各连接分支都能得到水。去重访问保证环路不会无限执行。关卡水管和参考解位于 `levels.js`，`solutionTiles(level)` 供测试验证，不在玩家界面自动解题。

```sh
node --test games/water-rescue/tests/*.test.mjs
```

测试包含：全部 15 关参考解可获得三星且初始状态不可直接通关、旋转不可变性、固定管不转、关闭阀门截流、分流与漏水、未连通备用管保持干燥、闭环终止、可一星通关。

首关手动解法：第 3 行第 3 列（坐标 `2,2`）旋转一次，然后开闸放水。

画面与音效均由本项目 SVG / Web Audio 原创生成。尚需实体手机和儿童试玩验证。
